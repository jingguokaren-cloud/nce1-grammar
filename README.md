# nce1-grammar

新概念英语第一册 72 节语法与练习页面。

## 学习记录

页面要求学生先使用家长创建的 CloudBase 账号登录，登录成功后才显示课程内容。以下内容会按账号分别保存在当前浏览器，并自动同步到云端；在其他设备登录同一账号时会合并恢复：

- 已完成题目和章节进度
- 作答区内容
- 错题本
- 生词本

密码只用于 CloudBase 登录，不会写入页面代码或浏览器学习记录。共用设备上的不同学生账号使用不同的本机存储空间，避免学习进度互相混入。

## 创建学生账号

进入 CloudBase 控制台的“身份认证 → 用户管理”，为每位学生创建独立账号。学生在网页顶部登录后，教师可以在“文档型数据库 → `nce1_student_progress`”查看每位学生的汇总进度和最后同步时间。
